# share-client

> ⚠️ **Are you set up with Yoti?**    
> 
> This package is a mini library to simplify the browser integration of Yoti Digital ID flow.
> 
> Before using it, make sure that you have created and activated a Yoti Digital ID service, and then that you have integrated it within your server.   


## What to use?

The project regroups a few packages, choose the one that corresponds to you case:

### Case 1: Types only please!
You are looking for types completion or types checking when integrating with the Yoti share client

➡️ You need [share-client-types](packages/types/README.md)

### Case 2: Simple code please!
You are looking for some simple code that creates a Yoti share for you.

➡️ You need [share-client-core](packages/core/README.md)

### Case 2: Simple, but in React, please!
You are looking for quick React components that render a Yoti share for you.

➡️ You need [share-client-react](packages/react/README.md)
